# Security Policy

MicroPython's [security policy](https://docs.micropython.org/en/latest/develop/security.html)
documents what is in scope, what to include in a report, how reports are handled, and which
versions receive fixes. Please read it before reporting.

## Reporting a vulnerability

Most security issues should be reported publicly using the
[security report form](https://github.com/micropython/micropython/issues/new?template=security.yml).

If an issue is readily exploitable, has high impact, or otherwise needs confidential handling, use
GitHub's [private vulnerability reporting](https://github.com/micropython/micropython/security/advisories/new)
instead. If you cannot use GitHub, email [contact@micropython.org](mailto:contact@micropython.org).
Do not disclose the details publicly while a report is handled privately.
