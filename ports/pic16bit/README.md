MicroPython port to 16-bit PIC
==============================

This is a port of MicroPython to Microchip 16-bit PIC microcontrollers,
specifically the dsPIC33F family and
[dsPIC33FJ256GP506](https://www.microchip.com/en-us/product/dsPIC33FJ256GP506).

This is a [Tier 3 MicroPython
port](https://docs.micropython.org/en/latest/develop/support_tiers.html) and is
not actively maintained.
