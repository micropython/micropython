The following firmware is applicable to any ESP32-S31 based module or
board, such as the ESP32-S31-WROOM-1 modules.

The default configuration assumes a module with 16 MiB of external SPI
flash and octal PSRAM, and enables native USB (TinyUSB CDC/MSC), the
UART REPL, BLE, and Wi-Fi (including Wi-Fi CSI).
